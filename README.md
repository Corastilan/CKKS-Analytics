# AppliedCryptographyProject3

##  Macbook M4 issues:
Had to create a separate Python venv for TenSeal.

### Steps:
1. brew install python@3.12
2. python3.12 -m venv tenseal_env 
3. source tenseal_env/bin/activate 
4. pip install --upgrade pip 
5. pip install tenseal scikit-learn numpy
6. Run the homomorphic_iris.py file
